# Testing Checklist

## Exam flow

- [ ] Questions load on startup.
- [ ] Selecting an option marks it as selected.
- [ ] Previous and Next navigation work.
- [ ] Question-number navigation works.
- [ ] Answered questions are visibly marked.
- [ ] Submission calculates the score.
- [ ] Restart returns to the first question.
- [ ] Timer counts down and submits at zero.

## Responsive checks

- [ ] Desktop layout is readable.
- [ ] Tablet layout stacks correctly.
- [ ] Mobile controls remain usable.
